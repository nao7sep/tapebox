# TapeBox

A local media library with web-import. TapeBox is a cross-platform Electron
desktop app that downloads videos from the web, keeps them in a tidy local
library, and lets you rename, organize, and export audio — all on your own
machine. No account, no cloud; your media and metadata stay under `~/.tapebox`.

## Features

- **Web import** — paste a URL to download video+audio (merged) via `yt-dlp`,
  with a sidecar `info.json` saved alongside each file.
- **Playlists & channels** — detect multi-item URLs and enumerate their entries
  before adding, so you can review what you're about to pull in.
- **Bulk add** — queue many URLs at once with configurable concurrency.
- **Library management** — list, filter, archive/unarchive, and remove items
  (optionally deleting the underlying files).
- **Rename to slug** — give a file a clean, stable name, optionally generated by
  an AI model from the video's title.
- **Local import** — bring existing media files on disk into the library.
- **Audio export** — export the whole track or one file per chapter, with
  stream copy or re-encode to MP3/FLAC.
- **Built-in player** — play items with chapter navigation.
- **Managed binaries** — `yt-dlp`, `ffmpeg`, and `deno` are downloaded and
  updated by the app itself into `~/.tapebox/bin`; nothing to install by hand.
- **Encrypted API keys** — provider API keys are stored with the OS keychain
  via Electron `safeStorage` (Keychain / DPAPI / libsecret); the plaintext key
  never touches disk.

## Requirements

- Node.js and npm
- macOS, Windows, or Linux (on Linux, OS keychain encryption requires
  `libsecret`; without it, API-key storage is disabled and surfaced in the UI)

## Getting started

```bash
npm install
npm run dev
```

Convenience launchers are provided that stop any leftover dev processes, install
dependencies, and start the app:

- macOS / Linux: `scripts/run.command`
- Windows: `scripts/run.ps1`

## Scripts

| Command              | Description                                      |
| -------------------- | ------------------------------------------------ |
| `npm run dev`        | Start in development mode (electron-vite)        |
| `npm run build`      | Build main, preload, and renderer bundles        |
| `npm run preview`    | Preview the production build                     |
| `npm run typecheck`  | Type-check with `tsc --noEmit`                   |
| `npm run pack:mac`   | Build and package an unpacked macOS app          |
| `npm run pack:win`   | Build and package an unpacked Windows app        |
| `npm run pack:linux` | Build and package an unpacked Linux app          |

## Data layout

All state lives under `~/.tapebox`:

```
~/.tapebox/
  bin/            managed yt-dlp / ffmpeg / deno executables
  library/        downloaded media + sidecar JSON
  logs/           per-launch log files (yyyymmdd-hhmmss-utc.log)
  work/           scratch space (in-progress downloads)
  config.json     settings
  session.json    queue/library state
  api-keys.json   encrypted provider API keys
```

## Architecture

TapeBox is split across three Electron contexts, each built separately by
electron-vite:

- **Main** (`src/main`, ESM) — owns all I/O: the download queue, `yt-dlp` /
  `ffmpeg` subprocesses, binary management, atomic JSON persistence, logging,
  and the OS keychain.
- **Preload** (`src/preload`, CommonJS) — exposes a typed IPC client to the
  renderer over the context bridge.
- **Renderer** (`src/renderer`, React 19 + Tailwind v4) — the UI, with Zustand
  stores for client state.

Shared code lives in `src/shared`:

- `ipc-contract.ts` is the single source of truth for IPC channels and events;
  both the main registrar and the renderer client derive their types from it.
- Zod schemas (`domain.ts`, `settings.ts`) validate everything read from or
  written to disk.

Path aliases `@main/*`, `@renderer/*`, and `@shared/*` map to the corresponding
`src` directories.

AI slug generation targets OpenAI-compatible providers; profiles (base URL,
model, name) are user-editable in Settings, and the API key is stored encrypted
per profile.
